Consulta durante o dia (comando /status)

De hora em hora, das 8h às 18h, o CRM guarda a versão mais recente do relatório no Supabase. Assim, quando alguém manda /status pro bot a qualquer momento do dia, ele responde na hora com os dados mais recentes salvos — sem precisar o CRM estar de olho o tempo todo.

Usa a mesma URL do projeto e Anon Key configuradas acima — não precisa cadastrar de novo.

Como configurar do lado do Supabase

Pro envio de relatório (horário fixo):

  1. No painel do Supabase, vá em Edge Functions e crie: enviar-relatorio e descobrir-chat-id, colando o código de cada uma.
  2. Em Edge Functions → Secrets, cadastre TELEGRAM_BOT_TOKEN com o token do seu bot.
  3. Cola a URL do projeto e a Anon Key aqui em cima (Settings → API no Supabase) e salva.
  4. Manda uma mensagem pro bot, clica "Descobrir Chat ID" aqui, e cola o ID na Secret TELEGRAM_CHAT_ID do Supabase.

Pra consulta a qualquer hora (comando /status):

  1. Rode o arquivo criar_tabela_relatorio_cache.sql no SQL Editor do Supabase (só uma vez).
  2. Crie mais duas Edge Functions: salvar-relatorio e webhook-telegram, colando o código de cada uma.
  3. Na function webhook-telegram, entre em "Details" (ou nas configurações da function) e desmarque "Enforce JWT Verification" — só nessa function específica. O Telegram não sabe se autenticar com o Supabase, então essa function precisa ficar aberta pra ele conseguir chamar.
  4. No navegador do celular (não precisa ser na máquina do CRM), abre essa URL uma vez pra registrar o aviso automático, trocando pelo seu token e pela URL do seu projeto:
    https://api.telegram.org/bot<SEU_TOKEN>/setWebhook?url=https://<SEU_PROJETO>.supabase.co/functions/v1/webhook-telegram
